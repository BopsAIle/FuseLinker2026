================================================================================
[5] Auxiliary network · compute_ppr_sparse  (dựng Gppr, chạy 1 lần trước train)
================================================================================

  train triples (src, rel, dst)
            |
            v
  A  = adjacency đối xứng, unweighted  (+ self-loop)
  M  = D^{-1/2} A D^{-1/2}             (transition, HGDC)
            |
            v
  PPR:  S <- c * M S + (1-c) E         (iterative, theo batch cột)
    hoặc S  = (1-c) (I - c M)^{-1}     (closed-form, N nhỏ)

  Backend (tự chọn, có fallback):
    CUDA iterative batched DGL  ->  CUDA dense inverse
    -> CPU batched DGL          ->  CPU sparse streaming (từng node)
            |
            v
  Sparse ~S :  bỏ self-loop, cắt |S_ij| < epsilon, giữ top-k / node
            |
            v
  Gppr + edge_weight     đồ thị thuần, KHÔNG có relation type


  Công thức (HGDC):
    s_i = c M s_i + (1-c) e_i
    PPR(s_i) = (1-c) (I - c M)^{-1} e_i
    S        = (1-c) (I - c M)^{-1}


================================================================================
[6a] DistMult  (link prediction — calculate_score / get_loss)
================================================================================

  relation_weights in R^{num_rels x hidden}   (pretrained hoặc Xavier)

  +----------------+   +---------------------+   +----------------+
  | h_s            |   | r                   |   | h_o            |
  | (subject emb)  |   | (relation_weights)  |   | (object emb)   |
  +--------+-------+   +----------+----------+   +--------+-------+
           |                      |                       |
           +----------------------+-----------------------+
                                  |
                                  v
               +------------------------------------------+
               |  score = sum( h_s  o  r  o  h_o )        |
               |  loss  = BCE(score, labels) + lam * L2   |
               +------------------------------------------+


================================================================================
[6b] SSL heads  (main3.py — KHÔNG dùng DistMult)
================================================================================

  Mask cạnh khỏi message-passing graph (lukepi_graph).
  Encoder chạy trên đồ thị đã mask -> h

  +------------------------------------+     +-------------------------------+
  | EdgeTypeClassifier                 |     | DegreeClassifier              |
  |------------------------------------|     |-------------------------------|
  | cat(h_src, h_dst)                  |     | Linear -> ReLU -> Drop        |
  | Linear -> ReLU -> Drop -> Linear   |     | -> Linear                     |
  | num_classes = num_rels + 1         |     | num_classes = num_degree_bins |
  | (R loại thật + 1 lớp fake edge)    |     | (bucket bậc, tính 1 lần)      |
  +-----------------|------------------+     +--------------|----------------+
                    |                                       |
                    v                                       v
              CE(edge logits)                         CE(degree logits)
                    |                                       |
                    +------------------+--------------------+
                                       |
                                       v
                         loss = loss_edge + loss_node
