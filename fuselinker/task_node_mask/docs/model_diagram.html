Pipeline — fuselinker/model.py

Luồng kiến trúc từ pretrained embeddings → RGCN → DistMult scoring.

LinkPredict
num_relations × 2 (cạnh thuận + nghịch) · backbone RGCN · DistMult

1. Input

  • graph, node_ids, rel_ids, norm
  • pretrained text embeddings · pretrained domain embeddings
  • tham số trộn w · freeze

2. EmbeddingLayer (input layer của RGCN)

Chuẩn hóa min-max [0,1] từng nguồn, chiếu về hidden_dim, rồi fuse.

Domain branch

  • norm_domain_embeddings
  • poincare_to_euclidean (Linear)
(1−w)·d + w·t
weighted avg

Text branch

  • norm_text_embeddings
  • TextEmbeddingAutoencoder
  • chỉ lấy encoded
h₀ = (1 − w) · domain_euclid + w · text_encoded

TextEmbeddingAutoencoder

Giảm chiều text embedding về hidden_dim.

  • Encoder: Linear → BN → ReLU → Dropout → Linear → BN → encoded
  • Decoder: tồn tại trong module nhưng EmbeddingLayer không dùng decoded

3. RGCN · RelGraphConv stack

BaseRGCN.build_model → chạy tuần tự các layer.

Layer 0
EmbeddingLayer node feature ban đầu · dim = hidden_dim
Hidden × N
RelGraphConv in = out = hidden_dim · num_rels×2 · regularizer='bdd' · ReLU trừ layer cuối
h = RGCN(graph, node_ids, rel_ids, norm)

4. DistMult scoring

relation_weights ∈ ℝnum_rels × hidden (pretrained hoặc Xavier).

hs subject embedding
r relation_weights[rel]
ho object embedding
score = Σ (hs ⊙ r ⊙ ho)
