FuseLinker — model.py pipeline
================================================================================

+------------------------------------------------------------------------------+
|  LinkPredict                                                                 |
|  num_relations x 2 (cạnh thuận + nghịch)  |  backbone: RGCN  |  DistMult     |
+------------------------------------------------------------------------------+
                                      |
                                      v
+------------------------------------------------------------------------------+
|  [1] INPUT                                                                   |
|------------------------------------------------------------------------------|
|  graph, node_ids, rel_ids, norm                                              |
|  pretrained text embeddings  |  pretrained domain embeddings                 |
|  w (trọng số trộn), freeze                                                   |
+------------------------------------------------------------------------------+
                                      |
                                      v
+------------------------------------------------------------------------------+
|  [2] EmbeddingLayer  (input layer của RGCN)                                  |
|------------------------------------------------------------------------------|
|                                                                              |
|  +---------------------------+      +------------------------------------+   |
|  | Domain branch             |      | Text branch                        |   |
|  |---------------------------|      |------------------------------------|   |
|  | norm_domain_embeddings    |      | norm_text_embeddings               |   |
|  | (min-max [0,1])           |      | (min-max [0,1])                    |   |
|  |           |               |      |           |                        |   |
|  | poincare_to_euclidean     |      | TextEmbeddingAutoencoder           |   |
|  | (Linear -> hidden_dim)    |      | (chỉ lấy encoded)                  |   |
|  +------------|--------------+      +------------|-----------------------+   |
|               |                                  |                           |
|               +--------------+-------------------+                           |
|                              |                                               |
|                              v                                               |
|               +------------------------------------------+                   |
|               |  weighted avg                            |                   |
|               |  h0 = (1 - w) * domain + w * text        |                   |
|               +------------------------------------------+                   |
|                                                                              |
+------------------------------------------------------------------------------+
                                      |
                                      v
+------------------------------------------------------------------------------+
|  [3] TextEmbeddingAutoencoder  (chi tiết text path)                          |
|------------------------------------------------------------------------------|
|  Encoder: Linear -> BN -> ReLU -> Dropout -> Linear -> BN -> encoded         |
|  Decoder: có trong module nhưng EmbeddingLayer không dùng decoded            |
+------------------------------------------------------------------------------+
                                      |
                                      v
+------------------------------------------------------------------------------+
|  [4] RGCN  (BaseRGCN.build_model, chạy tuần tự)                              |
|------------------------------------------------------------------------------|
|                                                                              |
|  +-----------------------------------------------------------------------+   |
|  | Layer 0: EmbeddingLayer  ->  h0  (dim = hidden_dim)                   |   |
|  +-----------------------------------------------------------------------+   |
|                                      |                                       |
|                                      v                                       |
|  +-----------------------------------------------------------------------+   |
|  | Hidden x N: RelGraphConv                                              |   |
|  |   in = out = hidden_dim                                               |   |
|  |   num_rels x 2                                                        |   |
|  |   regularizer = 'bdd'                                                 |   |
|  |   ReLU trên mọi layer trừ layer cuối                                  |   |
|  +-----------------------------------------------------------------------+   |
|                                                                              |
|  h = RGCN(graph, node_ids, rel_ids, norm)                                    |
|                                                                              |
+------------------------------------------------------------------------------+
                                      |
                                      v
+------------------------------------------------------------------------------+
|  [5] DistMult scoring                                                        |
|------------------------------------------------------------------------------|
|  relation_weights in R^{num_rels x hidden}  (pretrained hoặc Xavier)         |
|                                                                              |
|  +----------------+   +---------------------+   +----------------+           |
|  | h_s            |   | r                   |   | h_o            |           |
|  | (subject emb)  |   | (relation_weights)  |   | (object emb)   |           |
|  +--------+-------+   +----------+----------+   +--------+-------+           |
|           |                      |                       |                   |
|           +----------------------+-----------------------+                   |
|                                  |                                           |
|                                  v                                           |
|               +------------------------------------------+                   |
|               |  score = sum( h_s  o  r  o  h_o )        |                   |
|               +------------------------------------------+                   |
|                                                                              |
+------------------------------------------------------------------------------+


Tóm tắt luồng
-------------
  +--------+     +------------------+     +----------------+     +----------+
  | Input  | --> | EmbeddingLayer   | --> | RelGraphConvxN | --> | DistMult | --> score
  +--------+     | domain Linear +  |     +----------------+     +----------+
                 | text AE, fuse w  |
                 +------------------+
